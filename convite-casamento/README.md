# Convite de Casamento — Claudia Cristina & Max Alexandre

Site estático feito com HTML, CSS e JavaScript.

## Arquivos
- `index.html` — estrutura das telas.
- `style.css` — identidade visual e animações.
- `script.js` — abertura do envelope e navegação entre as telas.
- `assets/igreja.jpg` — foto da igreja (adicionar depois).
- `assets/convite.jpg` — imagem do convite (adicionar depois).

## Como adicionar as fotos
Envie as imagens para a pasta `assets` com estes nomes exatos:
- `igreja.jpg`
- `convite.jpg`

Se ainda não tiver as fotos, o site mostra espaços reservados automaticamente.

## Publicar no Render
1. Crie um serviço **Static Site**.
2. Conecte este repositório do GitHub.
3. Build Command: deixe vazio.
4. Publish Directory: `.`
5. Clique em **Create Static Site**.

O convite é uma página estática e não precisa de servidor ou banco de dados para funcionar.
